# wxscanless · 微信多账号免扫码登录器

Windows 桌面小工具：把微信 4.x 已登录过的账号**登录态存档**下来，之后可以一键
**免扫码登录**多个微信实例（上限与微信自身一致，4 个）。

- 运行环境：Windows 7/10/11 + 微信 4.x（`Weixin.exe`）
- 开发语言：Python 3.11，**运行期零第三方依赖**（`uiautomation` / `comtypes` 已随 `release\ext\` 一并分发）
- 全程后台操作：点击是向按钮句柄投递消息，状态判定走 UI Automation，
  **不抢鼠标键盘、不要求窗口在前台**

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动采集 | 后台监控微信登录成功的那一刻，自动把该账号的登录态收进档案 |
| 免扫码登录 | 一键把某个账号登进独立实例，无需手机确认 |
| 一键登录 | 批量登录所有"已收录且未在线"的账号，已在线自动跳过 |
| 在线状态 | 头像在线彩色 / 离线灰度，昵称在线绿加粗；微信最多 4 个实例 |
| 账号档案 | 一账号一份：`config` 对 + `host` 目录 + 头像 + 元信息 |

界面为固定宽度的竖条启动器，支持窗口内任意位置拖动、贴右边缘自动隐藏、
账号过多时滚动条 + 滚轮翻看。

## 原理要点

1. **登录态存在哪**
   `<数据根>\xwechat_files\all_users\config\global_config`（+ `.crc`）是一对
   MMKV 文件（AES-128-CFB 加密，密钥是微信 DLL 里的常量 `xwechat_crypt_key`），
   里面记着"这次该登录哪个账号"和免扫码票据；账号级的网络路由文件在
   `<运行区>\<槽位>\host\`。这两样合起来就是本工具存档的内容。

2. **实例槽位**
   微信 4.x 的运行时目录是 `<运行区>\net`、`net_1`、`net_2`、`net_3`，每个实例占一个。
   - 占用判据：微信对 `<槽位>\config.ini` 持有 `share=0` 的独占句柄，我们能独占打开
     就说明该槽位空闲（纯只读操作）。
   - 新实例落在**下标最小的空闲槽位**。

3. **当前账号判定**
   `<槽位>\kvcomm\monitordata_<uin>_<X>` 只在登录成功后写入，停在登录页时微信会清掉它。
   但微信**从不清理历史文件**，所以"有非零 uin"不能当作在线 —— 本工具用
   `monitordata_<uin>` 与 `monitordata_0` 的 **mtime 时间簇**判定"这次写入是登录还是登出"。

4. **免扫码登录**
   热替换 `global_config` 对（文件被内存映射占用时先 `rename` 让位，已在跑的实例不受影响）
   → 把该账号的 `host` 铺进目标槽位 → 启动实例 → 后台等登录窗口 →
   后台点「进入微信」→ 按 **pid** 判定是否真的进了主界面。
   期间已有实例的窗口会被短暂隐藏（微信的单实例"转交"机制所致），新实例一出现在
   登录页就立刻原样显示回来。

5. **为什么能"多开"**
   已有实例的主窗口**可见**时，再启动微信会被转交给它而不产生新进程；主窗口**不可见**
   时才会真正新建实例。所以本工具用 `ShowWindow(SW_HIDE)` 收起旧窗口 —— 注意不能用
   `WM_CLOSE`，那会让微信置上内部隐藏标记，窗口恢复后"点不动"。

## 目录结构

```
launcher.py          启动器（唯一被打包进 exe 的代码，负责加载 release\app.py）
release\
├─ app.py             界面与装配（tkinter）
├─ src\wxprof\       业务模块
│  ├─ paths.py       微信安装/运行/数据目录探测
│  ├─ process.py     微信进程识别与启动（Toolhelp32 + PEB，不调用外部命令）
│  ├─ slot.py        实例槽位：占用判据、目标槽位、host 读写
│  ├─ mmkv.py        global_config 解密与解析（纯 Python AES-128-CFB）
│  ├─ avatar.py      头像下载 + GDI+ 转 PNG（零第三方依赖）
│  ├─ vault.py       账号档案库
│  ├─ collect.py     采集链路
│  ├─ watcher.py     实时监控（2 秒一轮）
│  ├─ login.py       免扫码登录主流程
│  └─ ui.py          登录窗口 UI 自动化
├─ ext\              第三方依赖（uiautomation / comtypes，已 vendored）
└─ assets\icon.ico   图标
data\                账号档案（运行时生成，**不入版本库**）
logs\                运行日志
```

业务代码全部位于外置的 `release\` 目录，**更新功能只需替换该目录，无需重新打包 exe**。

## 使用

源码运行（需要 Python 3.11）：

```bat
python launcher.py
:: 或
python release\app.py
```

打包 exe（可选，仅用于分发）：见 `requirements.txt` 内的说明 —— 打包环境用
`_tools\pack_exe.py`（该目录不随版本库跟踪）。⚠️ Python 必须用 **3.11**：
3.13 下 `uiautomation` 的 COM 初始化会静默失败，登录功能整体失效。

首次使用：直接用微信正常登录一个账号 → 后台监控会自动把它收进档案 → 之后就能一键免扫码登录。

## 注意

- `data\` 目录里的登录票据在效力上等同于账号登录凭证，**请勿外传、不要上传到任何公开仓库**。
- 工具只读写本机的微信数据目录，不会修改微信程序本体；但它依赖微信的私有文件格式，
  微信升级后若格式变化可能需要重新采集。
- 仅供学习与自用，请遵守微信的用户协议。
