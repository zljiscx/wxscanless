# wxscanless · 微信多账号免扫码登录器

Windows 桌面小工具：基于官方原生微信 4.x，不依赖且不支持第三方多开补丁。**自动收录**已登录账号的登录态，之后可一键**免扫码**自动登录多个微信实例（数量上限受官方微信本身限制）。

- 运行环境：Windows 7/10/11 + 微信 4.x（`Weixin.exe`）
- 开发语言：Python 3.11，**运行期零第三方依赖**
- 全程后台操作，不抢鼠标键盘、不要求窗口在前台

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动采集 | 后台监控微信登录成功的那一刻，自动把该账号的登录态收进档案 |
| 免扫码登录 | 一键把某个账号登进独立实例，无需手机确认 |
| 一键登录 | 批量登录所有"已收录且未在线"的账号，已在线自动跳过 |
| 在线状态 | 头像在线彩色 / 离线灰度，昵称在线绿加粗；微信最多 4 个实例 |
| 账号档案 | 一账号一份：登录态配置 + 网络路由 + 头像 + 元信息 |

界面为固定宽度的竖条启动器，支持窗口内任意位置拖动、贴右边缘自动隐藏、账号过多时滚动条 + 滚轮翻看。

## 使用

### 首次使用

直接用微信正常登录一个账号 → 后台监控会自动把它收进档案 → 之后就能一键免扫码登录。

### 源码运行（需要 Python 3.11）

```bat
python launcher.py
```

### 打包 exe（可选）

⚠️ Python 必须用 **3.11**：3.13 下 UI 自动化会静默失败（`ui._OK = False`，
窗口探测返回空列表且不报错），登录功能整体失效。

打包 exe 属于可选的本地构建步骤，所用的打包环境不随本仓库发布。

## 目录结构

```
launcher.py          启动器（唯一被打包进 exe 的代码，负责加载 release\app.py）
release\
├─ app.py            界面与装配（tkinter）
├─ src\wxprof\       业务模块
├─ ext\              第三方依赖（已内置）
└─ assets\icon.ico   图标
data\                账号档案（运行时生成，**不入版本库**）
logs\                运行日志
```

业务代码全部位于外置的 `release\` 目录，**更新功能只需替换该目录，无需重新打包 exe**。

## 注意

- `data\` 目录里的登录票据在效力上等同于账号登录凭证，**请勿外传、不要上传到任何公开仓库**。
- 工具只读写本机的微信数据目录，不会修改微信程序本体；但它依赖微信的私有文件格式，微信升级后若格式变化可能需要重新采集。
- 仅供学习与自用，请遵守微信的用户协议。
